# 🚀 NEXORA

### AI & ML Product Design Agency Website

NEXORA is a modern frontend website for an **AI & ML Product Design Agency**.

It is designed to show AI/ML services, UI/UX design, product design, case studies, and the design process.

## ✨ Features

* Modern and clean UI
* Smooth scrolling
* GSAP animations
* Interactive navigation
* Hover effects
* Video showreel
* Case studies
* UI/UX and Product Design sections
* Responsive layout

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* GSAP
* ScrollTrigger
* Locomotive Scroll
* Remix Icon

## 📁 Files

```text
NEXORA/
├── NEXORA.html
├── style.css
├── script.js
└── README.md
```

## ▶️ Run the Project

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `NEXORA.html` in your browser.
4. You can also use **Live Server** in VS Code.
